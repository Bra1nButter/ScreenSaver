# ScreenSaver (Android 8.0+)

Утилита на базе **Flutter + Kotlin (Native)** для программного отключения экрана Android (API 26+) без приостановки активного приложения.

## Возможности

1. **Программное гашение экрана без остановки процессов (`TYPE_ACCESSIBILITY_OVERLAY`)**
2. **Мгновенное пробуждение кнопкой питания (1 нажатие), мультитачем (2–5 пальцев), двойным/тройным тапом, свайпом или кнопками громкости**
3. **Плитка быстрого запуска в шторке Android (`Экран ВЫКЛ`)**
4. **Автообновление внутри приложения (GitHub OTA без браузера):**
   - Автоматическая проверка новых релизов в `Bra1nButter/ScreenSaver`.
   - Прямое скачивание сжатого `arm64-v8a` APK с индикатором прогресса и установкой поверх текущей версии без сброса `AccessibilityService`.

## Выпуск новой версии (CI/CD через GitHub Actions)

Для выпуска нового релиза выполните в PowerShell:

    .\release.ps1 1.1.0 "Описание изменений"

Скрипт автоматически обновит `pubspec.yaml`, создаст тег `v1.1.0` и отправит его в GitHub, где GitHub Actions соберет облегченный сжатый APK и опубликует его в разделе Releases.
