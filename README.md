# ScreenSaver (Android 8.0+)

Утилита на базе **Flutter + Kotlin (Native)** для программного отключения экрана Android (API 26+) без приостановки активного приложения.

## Основные возможности

1. **Программное гашение экрана без остановки процессов:**
   - Накладывает поверх всех окон (включая строку состояния, навигационный бар и вырез камеры) абсолютно черный слой (`#000000`) через `TYPE_ACCESSIBILITY_OVERLAY`.
   - Снижает аппаратную яркость подсветки окна до `0%` (`screenBrightness = 0.0f`), не меняя системные настройки яркости.
   - Удерживает `FLAG_KEEP_SCREEN_ON` и `FLAG_NOT_FOCUSABLE`, благодаря чему активные игры, видео и камера продолжают работать в состоянии `onResume()`.
2. **Гибкие способы пробуждения (можно комбинировать):**
   - Физическая кнопка питания (всегда активна как защита).
   - Одновременное касание `N` пальцами (от 2 до 5 пальцев).
   - Двойной или тройной тап.
   - Свайп по экрану.
   - Физические кнопки громкости (`Volume Up / Down`).
3. **Быстрый запуск из шторки (Quick Settings Tile):**
   - Поддержка системной плитки `Экран ВЫКЛ` для мгновенного отключения экрана поверх любого открытого приложения.
4. **Режим «ТЕСТ (10 секунд)»:**
   - Безопасная проверка выбранных жестов разблокировки с автоматическим возвратом экрана через 10 секунд.
5. **Защита от выгрузки (Anti-Kill) и доп. опции:**
   - Запрос исключения из оптимизации батареи, чтобы Android не сбрасывал `AccessibilityService`.
   - Автоматическое пробуждение при входящем телефонном/мессенджер звонке.
   - Опциональный тусклый индикатор работы с защитой от выгорания OLED.

## Сборка и запуск через VS Code / ADB

1. Подключите устройство по ADB и проверьте его доступность:
   
       adb devices

2. Запустите проект в режиме отладки:
   
       flutter run

3. Для сборки релизного APK:
   
       flutter build apk --release

Подробное описание архитектуры и работы компонентов приведено в файле `DOCS.md`.
